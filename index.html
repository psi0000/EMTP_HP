EMTP: Efficient Multi-Robot Task Planning with Large Language Models

Seungin Park, Minjae Jung, Changseung Kim, Woojae Shin, Seunghoon Lee, Hyondong Oh

UNIST / KAIST
Paper Poster Videos Contact
Abstract

Dynamic task allocation in heterogeneous multi-robot systems requires efficient replanning under evolving environmental conditions and operator instructions. Conventional methods often rely on predefined models, while existing large language model (LLM)-based approaches suffer from increasing reasoning cost, hallucinations, and limited scalability when handling multiple tasks and dynamic constraints. This work proposes EMTP, an efficient multi-robot task planning framework that integrates 3D Scene Graph (3DSG)-based grounding with supervisor-based hierarchical LLM orchestration. EMTP selectively invokes semantic filtering, semantic reasoning, and optimization-based task allocation agents according to the type of dynamic event. This design reduces unnecessary reasoning overhead while supporting constraint-aware planning. The 3DSG provides structured environmental context for both LLM-based reasoning and optimization-based allocation. Simulation experiments in large-scale indoor environments demonstrate that EMTP achieves higher task completion and constraint satisfaction rates with lower planning computation time and token usage than existing LLM-based multi-robot planning methods, particularly in online replanning scenarios with accumulated dynamic constraints.

Method
Method 01

3DSG-Based Context Grounding

As shown in the overview figure, the 3D Scene Graph provides a shared planning context across Semantic Filtering, Semantic Reasoning, and Task Allocation. By grounding each replanning step in the updated 3DSG rather than accumulated dialogue history, EMTP reduces omission and inconsistency caused by long interaction context and supports consistent online replanning.

Method 02

Hierarchical Adaptive Orchestration

The Supervisor manages the replanning pipeline by adaptively invoking only the modules required by each dynamic event and reusing cached information whenever full reprocessing is unnecessary.

  • Semantic Filtering selects task-relevant objects from the full object list and constructs a compact filtered 3DSG context.
  • Semantic Reasoning interprets dynamic events as task exclusions, priority constraints, or spatial restrictions.
  • Task Allocation solves constrained assignment using verified context, robot capability, availability, and graph-based travel costs.
