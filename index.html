Abstract

Multi-robot task allocation (MRTA) in dynamic, unstructured environments demands real-time adaptability, semantic scene understanding, and scalable planning. Existing LLM-based approaches suffer from high inference costs, hallucination, and limited scalability when confronted with numerous robots, tasks, and spatial constraints simultaneously. We propose EMTP (Efficient Multi-Robot Task Planner), a unified framework integrating 3D Scene Graph (3DSG)-based semantic environment representation, hierarchical LLM orchestration, and combinatorial optimization. A Supervisor selectively invokes Semantic Filtering and Semantic Reasoning Agents based on event type, compressing large-scale environmental information into task-relevant constraints. These constraints are passed to a Google OR-Tools solver for optimal allocation and path planning. Validated on real robot hardware (1 Robot Dog + 2 UGVs) in a multi-floor indoor environment, and in simulation with up to 10 robots and 100 tasks, EMTP achieves a 70% reduction in LLM token cost and 86% reduction in planning time, enabling near-real-time replanning across diverse dynamic scenarios with 100% task completion rate.

Framework Overview

01

3D Scene Graph

Hierarchical semantic map encoding spatial–object–relational structure. Updated on dynamic events to maintain consistency.

02

Semantic Filtering

Prunes 3DSG to task-relevant objects only, compressing LLM context and improving reasoning accuracy.

03

Semantic Reasoning

Extracts physical and semantic constraints (spatial, priority, robot capability) from the filtered graph.

04

Optimization

Google OR-Tools solves the constrained MRTA problem for optimal allocation and path planning.
